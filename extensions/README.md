# Extensions

Advanced variants gated on parent-module quality:

| Extension | Prerequisite theme |
|---|---|
| Gene expression & target prioritization | Experimental design, multiple-testing control |
| Variants & resistance | Consistent variant↔sequence↔structure mapping |
| MM/GBSA or MM/PBSA | Adequate trajectories; treat as approximate |
| Enhanced sampling | Collective variables; uncertainty on free-energy profiles |
| QM/MM | Electronic-structure question; QM region justification |
| Molecular generation | Validated evaluator + explicit chemistry policy |

Proposals and prototypes will land here as separate folders when started.
