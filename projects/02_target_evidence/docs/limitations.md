# Limitations — Project 02

1. Catalog is a small curated subset of >500 CDK2-related PDB xrefs.
2. Isoform-specific structures and engineered constructs are not fully modeled.
3. Pairwise alignments ≠ phylogenetically weighted conservation.
4. Bundled coordinates for the HTML viewer are **1AQ1 chain A**; the top-ranked
   entry for an intent may differ — obtain full official files from RCSB for
   production work.
5. Crystal contacts, alternate locations and occupancy are not audited in depth.
6. AlphaFold is intentionally excluded from this demo’s validation claims.
