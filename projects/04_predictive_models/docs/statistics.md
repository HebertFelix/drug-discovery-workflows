# Statistics — Project 04

| Metric | Use |
|---|---|
| MAE / RMSE | Error magnitude on pIC50 |
| R² | Variance explained relative to test-set mean |
| Max Tanimoto to train | Simple applicability-domain proxy |

No hyperparameter search is performed on the test set. Train metrics are
diagnostic for underfitting/overfitting, not claims of generalization.
