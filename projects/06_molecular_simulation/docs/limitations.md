# Limitations — Project 06

1. Tens of picoseconds — pedagogical, not converged folding/binding sampling.
2. Implicit solvent (OBC2) lacks explicit water degrees of freedom.
3. No ligand; protein–ligand MD is deferred to the advanced track / case study.
4. H-bond geometric counts ≠ thermodynamic populations.
5. Autocorrelation estimator is a simple cutoff sum, not a full spectral method.
6. CPU platform only in the documented demo path.
